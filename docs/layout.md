# Layout

Everything for Linux/WSL is in `linux/`, everything for Windows in `windows/`. The root holds the entry point, the shared package list and the docs.

| Path | Linked to / does |
|---|---|
| `install.cmd` | the installer for both systems: Linux/WSL runs `linux/install.sh`, Windows runs `windows\install.ps1` ([install](install.md)) |
| `packages.yaml` | every package, for both systems ([packages](packages.md)) |
| `linux/zsh/zshrc`, `zshenv`, `zprofile`, `zsh_aliases`, `zsh_plugins.txt` | `~/.zshrc` etc.; plugins via antidote |
| `linux/starship/starship.toml` | prompt: user@host, cwd, virtualenv; on demand: duration, jobs, sudo, exit code |
| `linux/starship/starship-status.toml` | git/python/go/k8s/terraform, shown in byobu row 3; k8s contexts matching `prod` turn red |
| `linux/byobu/` | `~/.config/byobu/`: 4-row status bar, pulsing active tab, clickable key hints |
| `linux/byobu/bin/` | status scripts, `tab-search` (Alt-D popup), `tab-move`, `restore-tabs`, shared `fzf-theme` |
| `linux/trippy/trippy.toml` | `~/.config/trippy/trippy.toml`: trippy (`trip`) with AS names (DNS via Cloudflare: the system resolver can't look them up), IP and hostname per hop, SynthWave '84 colours. Only what differs from trippy's defaults. GeoIP isn't in it (trippy takes no `~` and stops if the file is missing): the `trip` function in `zshrc` adds `-G ~/.local/share/GeoIP/GeoLite2-City.mmdb` when that file is there. The installer asks once for a free MaxMind account ID and license key (saved for geoipupdate in `~/.config/GeoIP.conf`, mode 600; Enter skips, remembered in `~/.local/state/dotfiles/geoip-skipped`) and runs geoipupdate on each run; `--uninstall` removes the key file and the database |
| `linux/termscp/theme.toml` | `~/.config/termscp/theme.toml`: termscp in SynthWave '84 colours, backgrounds left to the terminal. Saving a theme from `termscp config` writes into the repo. sshs can't take hex colours, only a Tailwind palette name: the `sshs` alias in `zsh_aliases` picks `pink` |
| `linux/suzieq/suzieq-cfg.yml` | template for `~/.suzieq/suzieq-cfg.yml`, written (not linked) by `configure_suzieq` with the home directory and timezone filled in: SuzieQ doesn't expand `~` in paths (its CLI made a literal `~` dir) and shows UTC without a timezone. Data in `~/.suzieq/parquet`, logs in `/tmp/sq-*.log`. Rewritten each run while its first line is the installer's marker; a config without it is yours and left alone. `--uninstall` removes it, keeping the inventory and data. The `sq-poller` function in `zshrc` puts SuzieQ's uv env first on `PATH`: the poller starts workers with `#!/usr/bin/env python3`, which otherwise finds mise's python |
| `linux/kitty/dotfiles.conf`, `linux/kitty/theme.conf` | only when kitty is installed (the `kitty` entry in `packages.yaml`, on a desktop): both linked to `~/.config/kitty/`, and `include ~/.config/kitty/dotfiles.conf` is added at the end of each `kitty.conf` kitty reads, so they win over the rest of it and every session looks the same: `~/.config/kitty/kitty.conf` (e.g. Ubuntu's GNOME) and, if there, the Hyprland desktop setup's `~/.config/hypr/UserConfigs/kitty.conf` (it points `$KITTY_CONFIG_DIRECTORY` there under Hyprland). `dotfiles.conf`: login shell, `TERM=xterm-256color`, kitty's shortcuts off except copy/paste and new tab (`Ctrl-T`), `Ctrl-Shift-T` and `Ctrl-Shift-N` sent to byobu. `theme.conf`: the look: SynthWave '84 colours as in Windows Terminal (not wallust's from the wallpaper), and Departure Mono Nerd Font Mono at 16.5 pt (22 px: a pixel font is sharp only at multiples of 11 px; the `departuremono-nerd-font` entry), and the Hyprland desktop setup's feel (0.9 opacity; cursor trail), opening at 134 × 43 cells |
| `linux/hypr/dotfiles.lua` | only when Hyprland is installed (e.g. by a Hyprland desktop setup): linked to `~/.config/hypr/`, and loaded from the end of `UserConfigs/user_keybinds.lua` (a load error is printed to the Hyprland log as `[WARN] dotfiles.lua`). GNOME habits on top of tiling: keys in [hotkeys.md](hotkeys.md#hyprland-linuxhyprdotfileslua); click to focus (`follow_mouse = 2`) and `focus_on_activate`, set on `config.reloaded` because `user_settings.lua` loads later; an app's own minimize button minimizes; workspace 10 floats new windows; the desktop setup's dock starts at login; fcitx5 (Mozc, `Ctrl-Space`) starts with its environment. hyprbars title bars (the `hyprbars` entry in `packages.yaml`): drag to move, double-click or `□` to maximize, `–` minimizes, `✕` closes |
| `linux/hypr/windows.sh` | linked to `~/.config/hypr/dotfiles-windows.sh`: the `Alt-Tab` switcher (rofi, most recently used first, opened by a second `Tab` with `Alt` held, release `Alt` to pick; Hyprland sits in the empty `dotfiles-switch` submap meanwhile so `Tab` reaches rofi), minimize to `special:minimized`, the restore menu, and the count for waybar |
| `linux/desktop/record.sh` | linked to `~/.config/hypr/dotfiles-record.sh` (Hyprland) and `~/.local/bin/dotfiles-record` (COSMIC): screen recording on/off (`Ctrl-Alt-Shift-R` the screen, `Ctrl-Alt-Shift-A` an area picked with slurp) into `~/Videos/Screencasts` as in GNOME, no sound. wf-recorder under Hyprland, wl-screenrec elsewhere (COSMIC has no wlroots screencopy) |
| `linux/hypr/preset.sh` | with `--hyprland`: the answers given to the Hyprland desktop setup's installer (`--preset`): what its checklist opens with |
| `linux/hypr/hyprland-only.conf` | where Hyprland is installed: linked as a systemd drop-in for `hypridle`, `hyprpaper` and `swaync` (`~/.config/systemd/user/<unit>.service.d/`). Ubuntu enables their user services for every graphical session; with it they start only in Hyprland (`ConditionEnvironment=XDG_CURRENT_DESKTOP=Hyprland`), not in COSMIC or GNOME |
| `linux/hypr/panel.sh` | linked to `~/.config/hypr/dotfiles-panel.sh`: which panel runs, waybar + swaync (the desktop setup's, the default) or wayle. `dotfiles-panel.sh wayle` / `waybar` switches now and for later logins (the choice is the per-machine file `~/.config/hypr/dotfiles-panel`); while wayle is chosen it closes waybar and swaync whenever the desktop setup restarts them. The volume and brightness keys go through it (`key`): the desktop setup's scripts with waybar, the same change without their notifications with wayle (its own indicator shows it; its notifications would stack). With wayle it also watches wayle's idea of the default audio devices (D-Bus) against PulseAudio's: when headphones come or go, wayle can lose the new default and blank its volume and microphone modules; it then makes wayle read the defaults again (the default input moves away and back for a moment) and only restarts wayle if that doesn't help |
| `linux/hypr/swaync-panel.conf` | where Hyprland is installed: linked as a systemd drop-in for `swaync` (next to `hyprland-only.conf`): swaync starts only while waybar is the panel, since wayle has its own notifications |
| `linux/cosmic/SynthWave-84.ron` | with `--cosmic`: SynthWave '84 as a COSMIC theme (the kitty palette), frosted glass on. The installer imports it whenever it changes (COSMIC's importer takes no comments, so it strips them); also linked to `~/.config/cosmic-themes/` |
| `linux/cosmic/fcitx5.desktop`, `linux/cosmic/pivot.desktop` | with `--cosmic`: linked to `~/.config/autostart/dotfiles-*.desktop`, COSMIC only (`OnlyShowIn`): start fcitx5 and pivot (the `Alt-Tab` switcher) at login |
| `linux/cosmic/blueman.desktop` | with `--cosmic`: linked to `~/.config/autostart/blueman.desktop`, shadowing blueman's own: its tray applet starts everywhere but COSMIC (`NotShowIn`), where COSMIC's Bluetooth applet has the dropdown |
| `linux/cosmic/shortcuts.ron` | with `--cosmic`: copied to `~/.config/cosmic/com.system76.CosmicSettings.Shortcuts/v1/custom`, COSMIC's custom shortcuts (merged over its defaults): the Hyprland setup's keys, and screen recording. Copied, not linked: COSMIC Settings replaces a link when it saves. If the copy was changed in Settings, the installer leaves it and says so. A setting dropped from `COSMIC_KEYS` goes back to what it was before the first install, unless it was changed in Settings since. The other COSMIC settings (tiling on, workspaces side by side, the panel and dock) are in `COSMIC_KEYS` in `linux/install.sh` |
| `linux/cosmic/panel/` | with `--cosmic`: the panel's and dock's applets, in the format COSMIC Settings writes; copied by `COSMIC_KEYS` like the shortcuts, with the panel and dock see-through (0.45) and small |
| `linux/cosmic/input-applet/` | with `--cosmic`: this repo's COSMIC panel applet (Rust, libcosmic), built by the `cosmic-applet-input` entry in `packages.yaml` into `/usr/local`. Shows fcitx5's input method as `EN` / `あ` (asked over D-Bus a few times a second); click switches, right click opens fcitx5's settings. COSMIC's own Input Sources applet shows only the keyboard layout |
| `linux/wayle/config.toml` | linked to `~/.config/wayle/config.toml` where wayle is installed: bar layout, SynthWave '84 palette, minimized-windows count; its wallpaper engine off (awww sets the wallpaper). Changes from wayle's settings app go to `~/.config/wayle/runtime.toml` instead |
| `linux/wayle/styles/index.scss` | linked to `~/.config/wayle/styles/index.scss` where wayle is installed: CSS tweaks config.toml can't make (the menu button's icon size) |
| (`~/.local/share/icons/hicolor/scalable/apps/dotfiles-distro-logo.svg`) | where wayle is installed: the distro logo for wayle's menu button in a SynthWave gradient, made by the installer from the Simple Icons logo wayle installs (no logo in this repo). `--uninstall` removes it |
| (`~/.config/kanshi/config`) | untracked, per machine: kanshi profiles, monitor layouts applied when exactly those screens are connected (e.g. a `docked` and an `undocked` profile). kanshi is installed under Hyprland and started at login only when this file exists. Screen names from `hyprctl monitors`; see `man 5 kanshi` |
| (waybar, fcitx5) | only with Hyprland: `custom/minimized` (minimized windows; click to restore) is added to the desktop setup's `waybar/UserModules` and first in `modules-right` of every layout that includes it, each line marked `// dotfiles`. `WaybarStartup.sh` gets a first line that skips waybar while wayle is the panel. With fcitx5 installed (the `fcitx5*` entries in `packages.yaml`, where Hyprland or COSMIC is), `~/.config/fcitx5/profile` gets US keyboard + Mozc, and `~/.config/fcitx5/conf/waylandim.conf` gets `PersistentVirtualKeyboard=True` (otherwise fcitx5 lets go of `Alt` when an app loses focus, and `Alt-Tab` flips at once), each only if it doesn't exist; uninstall removes them unless they were changed. The desktop setup's waybar opens the wallpaper menu as `UserScripts/WallpaperSelect.sh` but ships it in `scripts/`: a link `~/.config/hypr/UserScripts/WallpaperSelect.sh` makes those clicks work. Older versions set the Quickshell overview to one row of 5 workspaces; Hyprspace replaced it, and the installer puts its `rows: 2` back. Uninstall undoes all of it |
| (GNOME input) | only on GNOME with ibus-mozc (the `ibus-mozc` entry in `packages.yaml`): GNOME's input sources get Mozc in place of Anthy (or added after the keyboard), and the input-source switch moves from `Super-Space` to `Ctrl-Space` (`Shift-Ctrl-Space` back), like fcitx5 under Hyprland. GNOME keeps ibus: with ibus installed, im-config's automatic choice stays ibus. The old values are kept in `~/.dotfiles-backup/`; uninstall puts them back unless they were changed since |
| `linux/hyprshell/config.toml` | only where hyprshell is installed (the `hyprshell` entry in `packages.yaml` builds it with cargo into `~/.local/bin`, only on GTK 4.18+, i.e. Ubuntu 26.04 on): linked to `~/.config/hyprshell/`, checked by the installer (`config check`), started by `dotfiles.lua` with `-c`. It binds `Alt-Tab` (switcher, all windows) and `Super-Space` (overview + launcher) itself over Hyprland IPC, so `dotfiles.lua` unbinds those instead of binding the rofi versions |
| `linux/hyprshell/styles.css` | linked to `~/.config/hyprshell/styles.css` where hyprshell is installed: its look (a dark translucent card, SynthWave pink on the selected window). hyprshell reloads it on save |
| `linux/wallust/SynthWave-84.json` | linked to `~/.config/wallust/colorschemes/` where wallust is (the Hyprland desktop setup's): SynthWave '84 as a wallust colour scheme, the kitty palette. Pick it in the desktop setup's theme menu (`Super-T`); it then holds across wallpaper changes, like its built-in themes. The installer edits that menu (`ThemeChanger.sh`) and `WallustSwww.sh` to list and apply schemes from that folder with `wallust cs`; `--uninstall` undoes it |
| (waybar `ModulesWorkspaces`) | the desktop setup's workspace modules keep 1 workspace (was 5), so the bar shows only the workspaces that exist. `--uninstall` puts 5 back |
| (VS Code `argv.json`) | only when Hyprland and VS Code are installed: `"password-store": "gnome-libsecret"` is added to `~/.vscode/argv.json`. Electron doesn't recognise Hyprland as a desktop, so without it VS Code says "An OS keyring couldn't be identified" and stores secrets unencrypted |
| `linux/vim/vimrc` | `~/.vimrc`; plugins via vim-plug into `~/.vim/plugged` |
| `windows/terminal/` | `settings.patch.json` merged into Windows Terminal's `settings.json` from WSL (scheme + defaults only), by `merge.py` |
| `windows/yasb/` | YASB status bar config, read in place via `YASB_CONFIG_HOME` |
| `linux/git/delta.gitconfig` | included from `~/.gitconfig`: delta as git pager (identity stays per machine) |
| `linux/install.sh`, `linux/install-fx.sh`, `linux/packages.py` | Linux/WSL installer, its look, and the package installer (also installs the Windows apps from WSL) |
| `linux/apt-deps` | for `packages.yaml`'s script steps: `install` adds only missing apt packages and records them, `own` records ones a step installed from a `.deb`, `remove` removes only recorded ones that apt can remove without taking anything else (never essential ones; one still needed stays as a dependency) |
| `windows/wallpapers.ps1` | Windows wallpaper picker (Start-menu shortcut `Ctrl-Alt-W`, made by `install.ps1`): Wallhaven search with thumbnails; a click downloads to `Pictures\Wallpapers` and sets it (Fill) |
| `tests/lint.sh`, `tests/run.sh`, `tests/lib.sh`, `tests/scenarios/` | checks and installer tests (Docker containers); see [development](development.md#checks) |
| `.githooks/pre-commit` | privacy check before each commit (secrets, emails, your own patterns); see [development](development.md#privacy-check-before-commits) |
| `.github/workflows/checks.yml` | CI: lint, gitleaks, the installer scenarios on Ubuntu 24.04 and 26.04, the Windows tests |
| `windows/install.ps1` | Windows bootstrap: apps, YASB, WSL, then the Linux installer inside WSL |
| `linux/monitoring-check`, `windows/monitoring-check.ps1` | read-only check run before installing a `private:` app (Beeper): prints the software found that can read this machine's files (endpoint security, DLP, file-query and forensics agents) or record its screen (activity monitoring). Nothing for network-only tools or device management: end-to-end encryption covers those, and what they deploy shows up once installed |
| `docs/` | these docs, `media/` (README recordings and screenshots, from a demo container), and `logo-v2.svg` (the README logo; renamed so browsers drop the old cached one) |
| `CLAUDE.md` | notes for AI agents: rules, release steps, testing, gotchas |

The installer also clones tmux-resurrect and tmux-continuum into `~/.tmux/plugins`. Tabs autosave every 15 minutes and are restored when byobu starts (`bin/restore-tabs`).
